# Waldaa Warra Wangeelaa Makaana Yesus Qaaqee

A Next.js website for a church community in Qaaqee, Dambi Dollo, Ethiopia, built with Tailwind CSS and Lucide icons.

## Overview

This project is a content-driven church site featuring:

- Home page with mission statement
- About page (`/about`)
- Sermons listing (`/sermons`)
- Ministries info (`/ministries`)
- Events page (`/events`)
- Gallery page (`/gallery`)
- Contact form/page (`/contact`)
- Prayer requests (`/prayer-request`)

## Features

- Next.js 13 app router structure
- Reusable UI components in `components/ui/`
- Responsive Tailwind layout and component styling
- Accessibility-first navigation and footer
- Integrations for Supabase data/migrations under `supabase/`
- Simple contact and prayer request forms
